# 4bit-cpu
## 概要
74HCシリーズのロジックICを使用して、自作CPUを設計、開発するプロジェクトです。

---

## 目的について
- CPUについて学び、実際に回路設計を行い、最終的に実際に動作する4bitCPUを制作すること。
- 制作過程を公開する。
  
---

## CPU仕様

| 項目 | 仕様 |
|---|---|
| データ幅 | 4bit |
| 命令長 | 8bit |
| レジスタ | 4bit × 8 |
| レジスタ番号 | 3bit |
| 命令種別 | 上位2bit |
| ALU | 6種類の演算 |
| 命令レジスタ | 8bit |
| PC | 4bit（予定） |

---

## レジスタ

| レジスタ | 用途 |
|---|---|
| REG0 | 汎用 |
| REG1 | ALU入力A |
| REG2 | ALU入力B |
| REG3 | ALU結果 |
| REG4 | 汎用 |
| REG5 | 汎用 |
| REG6 | 汎用 |
| REG7 | 汎用 |
